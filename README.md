# GPT Sidebar Manager

ChatGPT 프로젝트별 1단계 폴더, 채팅 정렬 및 프로젝트 채팅의 최근 목록 중복 표시를 관리하는 Chrome Manifest V3 확장입니다. 첫 완성본 버전은 `1.0.0`입니다.

## 설치 및 갱신

1. [GitHub Releases](https://github.com/Khyeum-AHAZ/GPT-Sidebar-Manager/releases)에서 `GPT-Sidebar-Manager-v1.0.0.zip`을 받아 영구적으로 사용할 폴더에 압축 해제합니다. 공개 저장소이므로 로그인 없이 다운로드할 수 있습니다. `manifest.json`, `src`, `popup`이 같은 폴더에 있어야 합니다.
2. Chrome 주소창에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 눌러 `manifest.json`이 있는 폴더를 선택합니다.
4. ChatGPT 탭을 새로고침하고 확장 아이콘을 눌러 프로젝트 인식 상태를 확인합니다.

기존 설치를 갱신할 때는 설치 폴더의 파일을 갱신한 뒤 **확장 카드의 원형 새로고침 버튼 → ChatGPT 탭 Ctrl+R** 순서로 적용합니다. 새 스크립트를 추가한 업데이트는 토글 ON/OFF만으로 적용 여부를 판단하지 마세요. 확장 삭제는 로컬 저장 정보에 영향을 주므로 업데이트 목적으로 삭제하지 않습니다.

## 기본 사용

- 프로젝트 이름 옆 `폴더＋` 아이콘으로 폴더를 만들고 채팅을 드래그해 분류합니다. 폴더 미지정 채팅은 프로젝트 아래에 바로 표시됩니다.
- 사용자 폴더를 우클릭하거나 옆의 `···`를 누르면 이름 변경·폴더 색상·삭제 메뉴가 열립니다. 색상은 기본색과 선명한 네온 계열 20종이며 아이콘에만 적용됩니다. 기존 폴더는 기본색을 유지합니다. 하위 폴더 아이콘 크기는 원본 프로젝트 아이콘의 약 95%입니다.
- 글자 스타일은 원본 채팅 행에서 읽어 적용하며 아이콘과 들여쓰기로 계층을 구분합니다. 동기화 상태는 사이드바 대신 확장 팝업에서 확인합니다.
- 기본 Safe Drag는 같은 프로젝트 안의 분류와 순서만 변경합니다.
- 채팅의 `···`는 ChatGPT 원본 메뉴를 엽니다.
- 팝업의 `GSM 사용 (이 기기)` OFF는 원본 목록을 복원합니다. 진행 중 이동/학습이 있으면 안전하게 종료된 뒤 반영됩니다. 이 설정은 해당 기기에만 저장됩니다.
- Chrome 확장 카드 자체를 OFF/ON했다면 ChatGPT 탭도 새로고침합니다.
- 현재 프로젝트 다시 읽기, 미학습 프로젝트 일괄학습, 모든 프로젝트 다시 학습을 팝업에서 실행할 수 있습니다. 학습 캐시 초기화는 사용자 폴더와 분류를 유지합니다.
- 네트워크 자동 인식(B)과 전체 드래그(Full Drag)는 실험 기능이며 기본 OFF입니다. `B 지금 다시 확인`은 자동 인식 설정을 바꾸지 않는 일회성 확인입니다.
- Full Drag는 실제 ChatGPT 프로젝트 소속을 변경합니다. 원본 메뉴가 잠깐 표시될 수 있으며, 복구 실패 메시지가 나오면 표시된 실제 소속을 확인해야 합니다.

## 회사 PC와 Chrome Sync

두 PC에서 같은 Chrome Google 계정과 확장 설정 동기화를 사용하고, ChatGPT도 같은 계정/작업공간으로 열어야 동일 프로젝트를 확인할 수 있습니다.

**두 PC의 확장 ID가 같아야 합니다.** 기존 PC와 새 PC의 `chrome://extensions`에 표시된 ID를 비교하세요.

현재 manifest에는 ID 고정용 `key`가 없습니다. 새 PC에서도 우선 기존 PC와 같은 절대 경로를 사용하고, 설치 후 확장 ID를 반드시 비교하세요. 같은 ZIP이라는 이유만으로 ID가 같다고 가정하지 않습니다. ID가 다르면 동기화 검증 전에 ID 유지와 기존 저장 데이터 보존 대책을 확인해야 합니다.

폴더(아이콘 색상 포함)/채팅 분류·순서와 실험 옵션은 동기화 대상이고, 학습 캐시와 `GSM 사용 (이 기기)`는 기기별입니다. 팝업의 `동기화 저장소에 기록됨`은 저장 API의 성공 표시이며 다른 PC 수신 완료를 증명하지 않습니다.

나중에 두 PC를 사용할 수 있을 때:

1. 한 PC에서 테스트 폴더를 만들고 채팅 하나를 분류한 뒤 다른 PC에서 반영을 확인합니다.
2. 다른 PC에서 해당 폴더 이름/분류를 변경하고 첫 PC에 반영되는지 확인합니다.
3. 실험 옵션 변경도 동기화되는지 확인한 뒤 양쪽에서 OFF로 돌립니다. Full Drag 동작은 실행할 필요가 없습니다.
4. 테스트 폴더와 분류를 원상복구하고 양쪽 결과를 확인합니다.

## 검증 상태

- Phase 1–8 구현과 단계별 검증 완료. Phase 9의 현재 PC 검증을 수행했으며 **실제 두 PC Chrome Sync는 사용자 확인 대기**입니다. 명세·코드 전체를 대조하는 최종 전체 검수도 남아 있습니다. 1.0.0은 사용자가 정한 첫 완성본의 버전이며 남은 검증의 완료를 뜻하지 않습니다.
- 자동 테스트 66개 통과: 원본 채팅 글꼴 참조, 모호한 소속 Fail-Open, 900개 최근 목록, 10개 프로젝트/150개 폴더, 색상 저장 호환성과 Sync 두 클라이언트 모형, 추가 버튼 드롭 차단/원본 복원, 반복 시작/종료, 내부 표시 스위치와 학습 취소 등을 포함합니다.
- 실제 Chrome: Safe Drag, 지정 채팅의 Full Drag 왕복, A+C 학습 및 B 관찰, 내부 OFF/ON과 OFF 재로드 유지, SPA 이동/뒤로가기, 사이드바 재열기, 페이지 재로드를 확인했습니다.
- 추가 UI 실제 확인: 프로젝트 옆 아이콘으로 빈 폴더 생성, 우클릭/··· 메뉴의 20색+기본색, 시안 저장 및 재로드 유지, 기본색 복원, 이름 변경, 삭제 확인, OFF/ON 시 추가 아이콘 제거/복원과 팝업 Sync 상태를 검증했습니다. 원본/GSM 채팅 글꼴은 14px/20px로 일치했습니다(현재 화면 기준). 사용자 피드백에 따라 아이콘 비율을 80%에서 95%로 조정했으며 최종 크기의 사용자 확인은 별도입니다.
- 대량 목록과 오류 주입/복구의 모든 경로를 실제 계정에서 재현한 것은 아닙니다. 자동 검증과 실제 확인 범위를 구분합니다.
- ChatGPT 화면 구조 변경 시 인식이 중단될 수 있습니다. 인식 실패 시 원본을 표시하는 Fail-Open이 기본입니다.

개발 검증은 프로젝트 루트에서 `node --test test/*.test.js`를 실행합니다. 명세는 `GSM_SPEC.md`를 참고하세요. 설치 ZIP에는 런타임 파일과 이 안내만 포함됩니다.

Chrome 공식 문서: [확장 ID 유지](https://developer.chrome.com/docs/extensions/reference/manifest/key), [확장 저장소와 Sync](https://developer.chrome.com/docs/extensions/reference/api/storage).
